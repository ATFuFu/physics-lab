一本可以玩的物理教科书

PHYSICS LAB · 以 60 px = 1 m 的真实单位搭建的 2D 物理沙盒

怎么玩

  • 从左侧元件库拖出小球、方块、弹簧或电池；单击放置默认大小，拖动可直接画出物件尺寸。再按 Space 暂停观察。
  • 空白处拖动框选多个物体，Shift + 点击增减选择；多选后可整体拖动、按 Alt 绕中心旋转，或批量固定/旋转/克隆/删除。
  • WASD / 方向键或按住中键拖动平移场景；滚轮、= / - 缩放。顶栏场地按钮切换 1× / 1.5× / 2× 世界。
  • 右键物体 / 铜线 / 弹簧 / 绳子打开快捷菜单，可即时调密度、摩擦、恢复、角度、宽高、场强、电压、电阻、张力等，也可固定、克隆或删除。
  • 铜线可以单独点击选中：点线身即可高亮，按 Delete 删除，或右键调电阻。
  • 拖拽松手会保留惯性；元件放置、碰撞、测量与按钮都有轻量音效，顶栏喇叭可静音。
  • 用底部的固定、旋转、删除按钮改造实验；按住 Alt 拖动或用 [ / ] 旋转物体。左右与底部的小三角可收起元件库、属性栏和工具栏。
  • 属性面板的“几何尺寸”可直接改圆的直径或多边形的宽高；场区也能改宽高与场强。
  • 弹簧、绳子、测力计：先点选元件，再依次点击两个物体或空白处（点空白处即固定在背景）。导线：依次点击两个金色接线柱。
  • 电场/磁场/重力场/风场会给区域内的物体施力；传送带靠表面速度带动物体，电磁铁通电后吸引铁球。斜面是真正的三角形刚体，斜面默认固定、三角块可自由下落；地面与场地边界用黑线标出。
  • 量子源会定时发射量子粒子；粒子可穿过双缝产生干涉、以一定概率穿过势垒；双击量子比特可测量坍缩。
  • 双击开关切换通断；双击量子纠缠对进行“测量”；双击量子粒子观察波包。

环境与参数

  • 真空（默认）：g = 9.81 m/s²，无空气阻力；地球：g = 9.81 m/s²，含空气阻力；月球：g = 1.62 m/s²。
  • 太空：零重力；水下：浮力 + 流体阻力，水线位于画布中下部。
  • 环境与场：电场施加 qE；磁场对运动电荷施加 qv×B；重力场叠加额外加速度；风场按迎风面积施加风压；传送带按表面速度摩擦带动物体。
  • 碰撞体：按模型轮廓生成——方块、三角、斜面、平台、长杆、电学件等使用真实多边形凸包，球类使用精确圆半径；场地边界也按旋转后的真实外框接触，不再用外接圆留出空隙。
  • 弹簧力、库仑力、空气阻力、浮力、电路电流均按下面的公式随时间步进计算。
ΣF = ma牛顿第二定律。所有刚体的质量由面积与等效密度计算，碰撞用冲量法求解。
F = −kx胡克定律。弹簧劲度系数 k 可在属性面板调节；测力计直接读出张力。
F = ½ρCdAv²空气阻力。轻羽片与铁球在地球环境中的下落差异由此产生。
F浮 = ρ液gV阿基米德原理。等效二维体积由面积给出，所以木球上浮、铁球下沉。
F = keq₁q₂/r²库仑定律。电荷球之间同性相斥、异性相吸，电场区会给电荷施加 qE 的力。
I = U/R · τ = RC欧姆定律与 RC 暂态。电池、电阻、灯泡、电容与铜线构成可求解的直流电路。
P = UI = I²R灯泡亮度由实际功率决定；电流表指针随电流偏转，导线上的光点表示电流方向。
T ∝ e−κa量子隧穿为示意模型：势垒越薄、粒子越快，穿过概率越大。

物理口径

重力取 9.81 m/s²，月球取 1.62 m/s²；世界比例为 60 px = 1 m。二维模型用“面密度”代替三维体积密度，因此浮力、质量与弹簧力的数值是同一套单位下的等效值。量子隧穿与纠缠测量为教学示意，不是完整的波函数数值解。
